# 消息助手 · 安装说明

给使用的人看的一页说明，不需要任何开发知识。

---

## 一、装之前

请先确认两件事：

1. **电脑上装了微信（个人版）并且已经登录过**。助手读的是微信自己的数据库，没有微信就没有数据。
2. **有一个大模型可以用**，二选一：
   - **云端模型**：一串 API key（一串以 `sk-` 开头的字符）。开箱即用，需要联网。
   - **本地模型**：自己装 [Ollama](https://ollama.com/download) 并下载一个模型。不联网，但要占几个 GB 硬盘。

没准备也可以先装，稍后在页面里补。

## 二、安装

1. 把 **`MessageAgent-Setup.cmd`** 和 **`MessageAgent-*.zip`** 两个文件放在**同一个文件夹**（不用解压 zip）。
2. **双击 `MessageAgent-Setup.cmd`**。它会自动把安装包解压到位并进入安装向导——
   不需要你手动解压整个包（整个包有几万个小文件，手动解压又慢又容易报"路径太长"）。
3. 按提示走完。中途只会问你一次：**用云端模型还是稍后配**。
   - 选云端：把 API key 粘进去（输入时不显示，粘贴后回车即可）。
   - 选稍后：装完在页面的「设置 → 模型」里贴进去，保存后立刻生效（见下面「配置模型」一节）。
4. 装完会自动打开浏览器进入助手页面，桌面上也会多一个「**消息助手**」快捷方式。

> 如果你已经手动解压了 zip：进到解压出来的文件夹，**双击里面的 `install.cmd`**，效果一样。

安装程序会做的事，一句话说清：把程序放到你的用户目录（**不会**动系统目录、**不需要管理员权限**）、
设置成登录后自动启动。

## 读消息的前提：已解锁目录

助手读消息**不是**去解密微信，它只读一份**已经解锁好的明文目录**（这份目录怎么来，
见下面）。装完之后如果页面提示"还没有读到会话"，按这个顺序补：

1. 向**交付你这套软件的人**要一份你机器上的「已解锁目录」（他会给你工具或代为操作）；
2. 把安装目录里 `config.json` 的 `unlocked_root` 改成那份目录的**绝对路径**；
3. 运行安装目录里的 `restart.ps1`，页面就有消息了。

换微信账号、或微信大版本升级后，原来的解锁目录不再对应新数据 —— 重新要一份新的，
重复第 2、3 步即可。已经整理过的内容不受影响。

## 配置模型（不配就没法用）

助手写回复、整理消息都要用一个大模型。两条路，选一条就行。

**A. 云端模型（推荐，开箱即用）**

1. 打开助手 → 左下角「设置」→ 找到「模型」那一块。
2. **在下拉里选一家**（DeepSeek / OpenAI / Claude / Gemini / 通义千问 / 智谱 / Kimi），
   点后面的「去哪拿 key →」去申请，把 key 粘进输入框。
3. 点「保存并启用」——**立刻生效**，不用重启。上面的"可用模型"会变多，
   再到模型选择里挑一个默认模型即可。

选「其它（自己填地址）」可以接任何 OpenAI 兼容的服务：填服务地址和模型名就行。

key 用 Windows 的密钥保护加密保存在这台电脑上，磁盘上没有明文。
安装时如果已经填过 DeepSeek 的 key，那一家不用再填。

**B. 本地模型（不联网，全部在这台电脑上跑）**

1. 右键安装目录里的 `install-local-model.ps1` → 使用 PowerShell 运行。
   它会自动装好 Ollama、下载模型（默认 qwen2.5:7b，约 4.7 GB）、接进助手并重启。
   （也可以在「设置 → 模型」的下拉里选「本地模型（Ollama）」—— 但模型得先有。）
2. 打开助手 → 设置 → 模型 → 「默认模型」里选「本地模型」。

机器一般、或想快一点，可以换更小的模型：

```
powershell -ExecutionPolicy Bypass -File install-local-model.ps1 -Model qwen2.5:3b
```

> 本地模型的好处是聊天内容完全不离开这台电脑；代价是回答质量不如云端，而且吃内存
> （7b 大概需要 8 GB 以上内存或 6 GB 以上显存）。

## 三、日常使用

| 想做什么 | 怎么做 |
| --- | --- |
| 打开助手 | 双击桌面的「消息助手」 |
| 停止 | 安装目录里的 `stop.ps1`（右键 → 使用 PowerShell 运行） |
| 出问题重启一下 | 安装目录里的 `restart.ps1` |
| 卸载 | 安装目录里的 `uninstall.ps1`（**默认保留你的数据**） |

## 四、关于隐私，你应该知道的

- **助手本体不解锁、不碰微信。** 它只读一份**别人产出的**已解锁明文目录（`unlocked_root`），
  不读进程内存、不取密钥、不打开微信窗口、不清未读红点。解锁那一步由交付方提供的独立工具完成，
  与助手是两个程序、两份数据。
- **不会替你发消息，除非你开了自动回复。** 自动回复默认是**关闭**的；每条规则都要你自己打开才会生效。
  发不出去或拿不准的消息，助手会留着让你自己决定，不会硬发。
- **API key 存在本机，加密保存。** 用的是 Windows 自带的密钥保护（DPAPI），磁盘上没有明文。
  别的 Windows 账号或把文件拷到别的电脑，都解不开。
  （要说清楚的一点：同一个 Windows 账号下运行的其他程序仍然可以解开——这是 Windows 密钥保护的
  边界，不是本产品的取舍。）
- **删除数据要你自己确认。** 卸载默认保留数据；要连数据一起删，必须显式确认。

## 五、常见问题

**页面打不开 / 打开是空白**
先运行 `restart.ps1` 再试。还是不行的话，把数据目录里 `logs` 下的 `harness.log` 发给开发者。

**提示"还没有读到会话"**
`config.json` 里的 `unlocked_root` 还没指向有效的已解锁目录：要么还没有这份产物
（找交付你的人拿，或用他给你的解锁工具生成一份），要么路径不对。
改好路径后跑一次 `restart.ps1`。

**自动回复不生效**
两个常见原因：① 规则是关闭状态（每条规则默认关闭，要手动打开）；② 大模型还没配好。

**想改配置**
页面上「设置」里的选项改完立即生效；极少数需要重启的，页面会提示你点 `restart.ps1`。

**数据在哪**
`%LOCALAPPDATA%\MessageAgent`（在文件管理器地址栏粘贴这一行就能打开）。
备份这个目录就等于备份了你的规则、待办和追踪记录。

## 升级到新版本

拿到新安装包之后，**不用先卸载**，直接覆盖装一遍就行：

1. 把新的 zip 解压到一个**新文件夹**（不要解压到旧的程序目录里）。
2. 双击安装目录里的 `stop.ps1` 把助手停掉（不停也行，安装程序会自己停掉它）。
3. 在新文件夹里**右键 `install.ps1` → 使用 PowerShell 运行**。
4. 看到这句就说明走对了：

   > 检测到这台电脑已经装过这个产品（上次：0.1.0）。按**升级**处理：
   > 程序文件更新到新版，你的聊天数据、待办、密钥、模型配置全部保留。

装完会自己打开页面。**你的东西一样都不会少**，因为数据存在
`%LOCALAPPDATA%\MessageAgent`，跟程序文件是两个地方，安装程序只在"文件不存在"时才写入。

**想回到旧版本**：把旧版的安装包解压，再运行一次它里面的 `install.ps1` 即可（数据同样保留）。
两边的版本号写在程序目录的 `.install-info.json` 里，想知道现在装的是哪一版，打开看一眼就知道。
