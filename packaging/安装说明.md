# 消息助手 · 安装说明

给使用的人看的一页说明，不需要任何开发知识。

---

## 一、装之前

请先确认两件事：

1. **电脑上装了微信（个人版）并且已经登录过**。助手读的是微信自己的数据库，没有微信就没有数据。
2. **有一个大模型可以用**，二选一：
   - **云端模型**：一串 API key（一串以 `sk-` 开头的字符）。开箱即用，需要联网。
   - **本地模型**：自己装 [Ollama](https://ollama.com/download) 并下载一个模型。不联网，但要占几个 GB 硬盘。

没准备也可以先装，稍后在页面里补。

## 二、安装

1. 把安装包解压到一个文件夹（**不要只复制其中的某一个文件**）。
2. 在解压出来的文件夹里，**右键 `install.ps1` → 使用 PowerShell 运行**。
   - 如果弹出"Windows 已保护你的电脑"：点「更多信息」→「仍要运行」。这是因为安装包没有买代码签名证书。
3. 按提示走完。中途只会问你一次：**用云端模型还是稍后配**。
   - 选云端：把 API key 粘进去（输入时不显示，粘贴后回车即可）。
   - 选稍后：装完在页面的「设置 → 模型」里补。
4. 装完会自动打开浏览器进入助手页面，桌面上也会多一个「**消息助手**」快捷方式。

安装程序会做的事，一句话说清：把程序放到你的用户目录（**不会**动系统目录、**不需要管理员权限**）、
把微信数据的读取方式初始化好、设置成登录后自动启动。

装完之后，如果页面上提示"还没有读到会话"，**在页面上点一下「读取微信密钥」**就行
（首页和「设置 → 微信数据」里都有这个按钮）。这一步是唯一需要读一次微信内存的动作，
所以助手不会自动做 —— 按下按钮后它会先跟你说明再确认，读完就把密钥加密保存到本机。

## 三、日常使用

| 想做什么 | 怎么做 |
| --- | --- |
| 打开助手 | 双击桌面的「消息助手」 |
| 停止 | 安装目录里的 `stop.ps1`（右键 → 使用 PowerShell 运行） |
| 出问题重启一下 | 安装目录里的 `restart.ps1` |
| 卸载 | 安装目录里的 `uninstall.ps1`（**默认保留你的数据**） |

## 四、关于隐私，你应该知道的

- **不会自动读微信内存。** 助手需要微信数据库的密钥才能读消息，而这个密钥只能从微信进程内存里
  取到一次。**只有你点了那个按钮才会去取**，任何时候都不会自动做这件事。
- **不会替你发消息，除非你开了自动回复。** 自动回复默认是**关闭**的；每条规则都要你自己打开才会生效。
  发不出去或拿不准的消息，助手会留着让你自己决定，不会硬发。
- **API key 存在本机，加密保存。** 用的是 Windows 自带的密钥保护（DPAPI），磁盘上没有明文。
  别的 Windows 账号或把文件拷到别的电脑，都解不开。
  （要说清楚的一点：同一个 Windows 账号下运行的其他程序仍然可以解开——这是 Windows 密钥保护的
  边界，不是本产品的取舍。）
- **删除数据要你自己确认。** 卸载默认保留数据；要连数据一起删，必须显式确认。

## 五、常见问题

**页面打不开 / 打开是空白**
先运行 `restart.ps1` 再试。还是不行的话，把数据目录里 `logs` 下的 `harness.log` 发给开发者。

**提示"还没有读到会话"**
多半是密钥还没取。在页面上点一次「读取微信密钥」等它跑完；页面上点不动时，
也可以右键运行安装目录里的 `read-wechat-keys.ps1`（要输入 YES 确认）。

**自动回复不生效**
两个常见原因：① 规则是关闭状态（每条规则默认关闭，要手动打开）；② 大模型还没配好。

**想改配置**
页面上「设置」里的选项改完立即生效；极少数需要重启的，页面会提示你点 `restart.ps1`。

**数据在哪**
`%LOCALAPPDATA%\MessageAgent`（在文件管理器地址栏粘贴这一行就能打开）。
备份这个目录就等于备份了你的规则、待办和追踪记录。
